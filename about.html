Data Preprocessing Pipeline

1
Missing Value Imputation

Numerical columns are imputed using the Mean value. Categorical columns (including Credit History) are filled using the Mode.

2
Label Encoding

Demographic parameters (Gender, Married, Education, Dependents, Self Employed, Property Area) are converted to ordinal integer values.

3
Feature Scaling

A StandardScaler is applied to normalise values across numerical metrics (ApplicantIncome, CoapplicantIncome, LoanAmount, Loan Term).

4
Class Balancing (SMOTE)

SMOTE generates synthetic examples for the minority class, raising the default rejection counts to balance approvals before training.

Methodology Statement:

The pipeline isolates the testing split before applying SMOTE to prevent data leakage. In cases of identical F1-score outputs, the system prioritizes XGBoost due to its performance stability across ensemble tree iterations.
